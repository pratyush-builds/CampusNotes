# Campus Notes Management System

A simple Python command-line application for managing notes.

## Features

- View saved notes
- Add new notes
- Search existing notes
- Exit the application through the main menu

## Requirements

- Python 3

## How to Run

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Run the following command:

   python main.py

4. Select an option from the menu.

## Menu Options

1. View Notes
2. Add Notes
3. Search Notes
4. Exit

## Project Structure

- main.py - Application entry point and menu
- notes.py - Note management functions
- notes/ - Directory for notes
- README.md - Project documentation

## Purpose

This documentation helps new users understand the project,
its features, and how to run the application.
